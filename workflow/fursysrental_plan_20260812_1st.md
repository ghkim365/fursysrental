## 2. 초절약 아키텍처 적용 시 예상 Quota 소진량 보고서

### Q. 초절약 아키텍처로 구현해도 기능 구현에 문제가 없나요?
**A. 전혀 문제없습니다.** 
본 웹사이트의 핵심 요구 기능(577개 가구 리스트 조회, 카테고리 필터링, 장바구니 실시간 금액 산정, 렌탈 문의 폼 접수 및 파일 업로드)은 복잡한 백엔드 트랜잭션이나 실시간 동기화가 불필요합니다. 
* **데이터 관리**: 577개 상품 데이터를 관계형 DB 대신 `products.json`이라는 정적 파일로 생성하여 클라이언트 사이드에서 즉시 로드 및 필터링 처리를 수행합니다. 500여 개 수준의 데이터량은 모바일 브라우저에서도 10ms 이하로 즉각 필터링되므로, 서버 데이터 요청(API 통신) 딜레이가 사라져 오히려 체감 UX 속도가 향상됩니다.
* **접수 처리**: 복잡한 메일 발송 서버를 직접 개발하는 대신, 이메일 전송 API(EmailJS 또는 Webhook 등)를 사용하여 문의 내역 및 개인정보, 첨부파일 링크를 즉시 수신 메일함으로 연동함으로써 안전하고 가볍게 대체할 수 있습니다.
